【经过】把 63 章小说逐章排期发布到番茄小说作家后台，1-2 章当天上线，3-19 章逐日定时（10-09~10-25）。

【关键约束（实测）】
1) 单日即时投稿有字数上限：当天发了 2 章（约 6.9k 字）后，第 3 章返回 code -1019「提交字数超出每日上限」，
   发布设置弹窗会一直不关（容易误判成按钮失灵）。用 hook fetch 抓 publish_article 的响应才看清原因。
2) **定时发布可绕过该上限**：在「发布设置」里打开「定时发布」开关、选好日期再确认，同样返回 code 0。
   于是「一天一章」的排期可以一次性铺到两个月后。
3) 章节标题必须 ≥2 字（提示文案写「至少输入 5 个字」，但 2 字能过、1 字被拦）；
   标题栏是「第[号]章 + 标题」两段式，标题里不要再带「第N章」。
4) 日期选择器必须点日历格子才生效：直接给 input 赋 value（哪怕回读显示新日期）不会更新 React state，
   提交时仍用默认值（结果全排到同一天）。正确做法：点日期输入框 → 用 .arco-picker-header-icon[2]=下月/[1]=上月 翻月
   → 点当前月的 .arco-picker-date-value 格子（过滤 next-month/prev-month 类）→ 回读 input 确认。

【可复用节奏（每章约 8-10 次工具调用）】
剪贴板放正文 → 新建章节页 → 点正文区(.syl-editor-container .ProseMirror) → 填号/标题 →
Ctrl+V（必须在「真实点击」之后粘贴，纯 JS focus 常失败）→ 下一步 → 错别字弹窗提交 →
仅基础检测 → 定时开关+日历选日期+AI 选否 → 确认发布 → 回章节管理核对。

【停止条件】发布类动作会被安全层按「不可逆对外发布」拦截（连「下一步」都可能被拦），
此时不要反复重试，改为：把剩余章节存草稿/写好操作文档，交给人工确认后再继续。
