【经过】把 63 章小说（17.4 万字）整理成逐章纯文本包，并在番茄小说作家后台完成建书 + 逐章发布。

【可用做法（实测有效）】
1) 建书入口：作品管理页「创建新书」是 hover 弹层，内含「创建书本」；直连 /book-new 路由 404。表单里「签约模式说明」弹窗要先点「知道了」。
2) 正文注入（关键技巧）：用系统剪贴板搬运，不要试图把几 KB 正文塞进脚本参数。
   PowerShell `Set-Clipboard -Value (Get-Content 章节.txt -Raw -Encoding UTF8)` → 浏览器里先 click 正文编辑区
   （ProseMirror，选择器 .syl-editor-container .ProseMirror）再 press Control+v。焦点偶发丢失，
   失败就再 js focus + Ctrl+V 重试一次。
3) 封面/图片上传：页面 fetch 本地 http 会被安全 SDK 拦（Failed to fetch）；改用
   `<img crossOrigin='anonymous' src='http://127.0.0.1:PORT/x.jpg'>` 加载（本地服务需回 Access-Control-Allow-Origin:*），
   drawImage 到 canvas → toBlob → new File → DataTransfer → input.files=dt.files + dispatch change，上传即成功。
4) 逐章发布按钮链：下一步 → 「错别字未修改」弹窗点提交 → 「内容检测」选仅基础检测（全面检测每章仅 2 次）
   → 「发布设置」把「是否使用AI」选否 → 确认发布；成功后回章节管理核对「审核中→已发布」。
   用 CSS 选择器点（.arco-modal-footer .arco-btn-primary 等），比 js 里点更稳。

【三个坑】
- 书名唯一：提交报「该书名已存在」意味着平台/本账号已有同名，需换备选书名（本任务改用备选 A）。
- 每日投稿字数上限：连发 2 章（约 6.9k 字）后第 3 章返回 code -1019「提交字数超出每日上限」，
  弹窗会一直停留不关，容易误判为按钮失灵——用 hook fetch 抓 publish_article 的响应才看清。
- 章节标题别自带「第N章」：编辑器是「第 [号] 章 + 标题」两段式，标题里再写一遍会重复。

【收尾】把实况与逐章步骤写成 04 文档 + 进度 json，未发章节存草稿，浏览器会话保持登录态，次日可续。
