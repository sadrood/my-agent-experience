【背景】用户要宫崎骏风格短片，但我方 video_gen 只有文生视频入口（无首帧参数），用户说"先写脚本，到时候会有图生视频功能"。

【做法】
1. 分镜与代码分离：storyboard.json 存每镜 keyframe 提示词（含 {{character}} 占位 + 统一角色锚点）、motion 运动描述、narration、duration、motion_fallback。
2. 四阶段可断点续跑（images / video / audio / assemble），每镜缓存在 build/<id>/，存在即跳过，--force 重做，--shots 部分重跑。
3. 后端适配层 I2VBackend（available/render），注册表 BACKENDS；auto 顺序 native → http → kenburns，首个成功即锁定该后端、但始终把 kenburns 留在队尾兜底。
   - native 先 inspect.signature(VideoGenModel.create) 看有没有 image/first_frame 参数；有则走官方入口，SDK 未跟上时 raise BackendUnavailable 自动降级。
   - http 用 I2V_ENDPOINT/I2V_STYLE(multipart|json_b64)/I2V_FIELD/I2V_TOKEN/I2V_STATUS 描述任意第三方协议，响应里递归找 url。
   - kenburns 兜底：静态图 + 运镜，永远可用。
4. 时长对齐 fit_clip：长了 trim；短了 setpts 慢放（≤2×，再多补 tpad 克隆帧）；旁白比画面长时**拉长画面**（kenburns 按新时长重渲染，真视频则慢放），绝不裁配音尾巴。
5. 字幕按累计时间轴生成 SRT，subtitle 烧录后手动删同名 .ass 中间文件。

【关键教训】
- **不要盲发带首帧字段的请求**：服务端常忽略未知字段并按文生视频处理，白烧配额且画面与原图无关，脚本还会误判成功。改成必须 I2V_GUESS=1 显式开启试探。
- models.video_edit 的类是 VideoEditor（不是 VideoEditModel），写脚本前先 code_index outline 确认符号名。
- add_audio 以画面为准（-t v_dur），配音超长会被切；必须先保证画面够长。
- video_edit.subtitle 会留下同名 .ass，交付前清理，否则 output 只涨不减。
- 视觉复核用 see 抽帧即可判断字幕遮挡/黑帧/风格统一，模型不可用会自动降级。

【可复用】需要"现在没能力、将来会有"的管线时，先做能力探测 + 多后端注册表 + 永远可用的兜底，把"切换"成本降到一行参数。
