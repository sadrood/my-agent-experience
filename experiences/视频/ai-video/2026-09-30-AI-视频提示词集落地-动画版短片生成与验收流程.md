## 经过
把《雨夜热饮》真人版提示词集转成"动画版"（日式二维动画/赛璐璐平涂/清晰黑色描边/高饱和霓虹色），5 镜 × 5 秒、16:9，用 agnes-video-2.5-flash 逐镜生成 → concat → 复用已有 BGM+Foley 音轨合成成片。

## 失败点 / 关键教训
1. **"画面中不出现任何招牌/海报/商品文字"这条要求，视频模型基本做不到**。日式动画 + 便利店场景是强先验，模型会自动补日文店招、货架价签、商品包装字。连试 4 版（v1 原版 / v2 加"焦外虚化" / v3 加中文+英文 no readable text / v4 把"没有招牌海报价签、标牌位置留白"提到 prompt 开头）仍能画出假名色块。结论：这类"移除某类元素"的负向要求，靠 prompt 重试收益很低（4 版都躲不掉），选最干净的一版交付并如实说明，比无限重试划算。
2. **视觉模型（备用 lite 模型）会幻觉读字**：同一位置不同帧读出完全不同的假名（"7-Eleven"、"フランクフルト"、"テツテテドゥー"），且 Windows OCR（zh-Hans + en-US 语言包）在同一帧上一个字符都读不出来。判定"有没有可辨识文字"要用 **OCR 兜底**（拉丁字母/数字可读，日文因语言包缺失读不出），不能全信视觉模型的转述。
3. 视频生成队列会 503 video_queue_full：接到就等 30-60 秒重试同一 prompt，不要改 prompt 重来。
4. 单镜生成常常卡在"进度 10%"一两分钟，是上游排队，不是失败。

## 可复用步骤
1. 用 video_gen(generate, seconds=5, aspect_ratio=16:9, size=720P) 逐镜串行生成；每镜出片后 ffmpeg 抽帧（fps=2）+ see/ocr 验收，通过再进下一镜。
2. 验收要点按提示词集的锚点逐条对：风格（二维动画/描边/平涂）、角色连续性（发型/外套颜色/兜帽状态）、道具（杯身无印刷）、核心动作是否真的生成出来（如"白雾升起"）。
3. 帧图工具：本机无系统 ffmpeg，用 `C:\Users\Administrator\.workbuddy\binaries\python\envs\default\Lib\site-packages\imageio_ffmpeg\binaries\ffmpeg-win-x86_64-v7.1.exe`；联系表要加 `-frames:v 1 -update 1`，否则 image2 复用器报"filename does not contain an image sequence pattern"。
4. concat 用 video_edit(concat)：同规格（1280x720/5.18s）会走无损 copy，25.95s 秒级完成；音轨用 video_edit(add_audio) 铺，复用同一系列已验证的 BGM+Foley 混音文件即可（时长对齐 25.95s）。
5. 成品验收：probe 读时长/分辨率/音轨 + volumedetect 确认 mean_volume 在 -20~-30 dB（有声、未削波）+ 逐秒联系表看节奏与风格是否统一。
