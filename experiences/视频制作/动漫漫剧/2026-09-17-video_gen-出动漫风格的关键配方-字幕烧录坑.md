【经过】用户要动漫风格漫剧，用 agnes-video-2.5-flash 直生成。第一版 prompt 只写"2D动画风格、勾边、平涂"，模型输出成电影写实数字绘画，被用户否掉。

【失败点/关键教训】
1. video_gen 默认偏写实渲染，光写"动漫/勾边/平涂"无效；必须把风格写成具体参照："新海诚式日本二维手绘动画电影风格，像《你的名字》《天气之子》"，外加"动漫脸：大眼睛、小鼻子小嘴、尖下巴、粗黑描边、大面积平涂高饱和"，负面写"绝对不是写实照片、绝对不是3D渲染"。这样才出日系动漫脸（测试确认可行）。
2. 角色一致性靠固定外貌描述：每次生成都把"清瘦、黑发微长、深灰风衣白衬衫"写进 prompt。
3. 字幕烧录：video_edit subtitle 工具默认按 288 高度基准缩放，竖屏 720x1280 下字幕会被放大到占半屏（用户两次抱怨！）。必须自己生成 ASS：PlayResX=720/PlayResY=1280、ScaledBorderAndShadow=no、Fontsize=24、SimHei、MarginV=90，再用 ffmpeg ass= 滤镜烧录；字体名带空格（如 Microsoft YaHei）会导致 filter 初始化失败，用 SimHei 无空格名字即可。
4. video_gen 限流 429（免费额度）：一次并行最多 3-4 个，等 1 分钟再继续；参数顺序要正确（prompt 必须在 prompt 参数里，别放错槽位）。
5. 拼接前先 probe 配音与画面时长：配音长于画面会被截断，用 ffmpeg tpad=stop_mode=clone 冻结尾帧延长画面。

【可复用步骤】固定风格前缀写 prompt → 分批生成（每批≤4）→ probe 时长对不齐就用 tpad → 逐镜 add_audio → concat → 钢琴 BGM 用 ffmpeg amix（add_audio 双音轨会报错）→ 自写 ASS 锁竖屏参数烧字幕 → 抽帧视觉验证。
